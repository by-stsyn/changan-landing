## 📂 Структура файлов для Reg.ru

В репозитории уже подготовлены и настроены все необходимые файлы для корректной работы на хостинге **Reg.ru**:

- **`.htaccess`** (и **`public/.htaccess`**):
  - Обеспечивает работу React SPA маршрутизации: при переходе по прямым ссылкам на автомобили (например, `https://sale.pragmatika-changanauto.ru/car/LS4ASE2EXRA272343`) сервер не выдает ошибку 404, а корректно отдает `index.html`.
  - Включает **Gzip/Deflate** сжатие (CSS, JS, SVG, XML, JSON) — сайт загружается в 3–5 раз быстрее на мобильных устройствах.
  - Настраивает кэширование браузера: тяжелые ресурсы кэшируются на 1 год, а `index.html` и фид всегда отдаются актуальными.
  - Настроен безопасный редирект на HTTPS с учетом Nginx reverse proxy в Reg.ru.
  - Закрывает доступ к конфиденциальным файлам (`.git`, `.env`, `package.json`).

- **`public/proxy.php`**:
  - Быстрый серверный прокси фида автодилера Maxposter.
  - **Автоматическая фильтрация**: исходный фид весит 13.3 МБ (1400+ машин всех марок). Скрипт прямо на сервере отбирает только автомобили **Changan** и отдает браузеру сжатый XML размером всего ~450 КБ. Это ускоряет загрузку каталога с 4 секунд до 50 миллисекунд.
  - **Кэширование**: сохраняет результат в системный кэш хостинга на 30 минут (`sys_get_temp_dir()`).
  - **3 уровня надежности**: свежий фид -> кэш хостинга -> локальный файл `changan-feed.xml`.

- **`.github/workflows/deploy.yml`**:
  - Готовый сценарий GitHub Actions для автоматической сборки (`npm run build`) и выгрузки по FTP/SFTP на Reg.ru при каждом пуше в ветку `main`.

- **`.gitignore`**:
  - Исключает из коммитов `node_modules`, временные файлы, логи и переменные окружения.

## 🛠 Развертывание на хостинге Reg.ru

### Вариант 1: Сборка и загрузка через FTP / Панель Reg.ru (Самый простой)

1. Соберите проект на своем компьютере:
   ```bash
   npm install
   npm run build
   ```
2. В корне появится папка `dist/`.
3. Зайдите в панель управления Reg.ru (**ISPmanager** или **cPanel**):
   - Откройте **Менеджер файлов** -> найдите корневую папку домена `sale.pragmatika-changanauto.ru` (обычно это `www/sale.pragmatika-changanauto.ru` или `public_html`).
   - Загрузите **все содержимое папки `dist/`** внутрь этой директории (включая файл `.htaccess` и скрипт `proxy.php`).
4. Убедитесь, что в панели Reg.ru для домена включен **PHP 7.4, 8.0, 8.1, 8.2 или 8.3** с включенным модулем `curl`.

---

### Вариант 2: Автоматический деплой через GitHub Actions

В файле `.github/workflows/deploy.yml` уже настроен автоматический пайплайн. Чтобы он заработал:

1. Перейдите в ваш репозиторий на GitHub: **Settings** -> **Secrets and variables** -> **Actions** -> **New repository secret**.
2. Добавьте три секрета (данные берутся в панели Reg.ru -> раздел «FTP-пользователи»):
   - `REG_RU_FTP_SERVER` — хост FTP (например, `ftp.pragmatika-changanauto.ru` или IP вашего сервера).
   - `REG_RU_FTP_USERNAME` — логин FTP-пользователя.
   - `REG_RU_FTP_PASSWORD` — пароль FTP-пользователя.
3. Теперь при каждом выполнении `git push origin main` GitHub сам автоматически соберет проект и обновит файлы на хостинге Reg.ru.

## 🔒 Проверка SSL-сертификата в Reg.ru

Для работы по протоколу `https://sale.pragmatika-changanauto.ru/`:
1. В панели управления Reg.ru перейдите в **SSL-сертификаты** (или **Управление сайтом** -> **SSL**).
2. Выберите бесплатный сертификат **Let's Encrypt** для домена `sale.pragmatika-changanauto.ru`.
3. Нажмите «Выпустить» / «Установить». Сертификат активируется за 5-15 минут.
